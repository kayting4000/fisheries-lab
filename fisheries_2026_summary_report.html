📊 Power BI – Step-by-Step Setup Guide

Load CSVs, build star schema model, create visuals, export PDF

Step 1 – Load the 5 CSV Files

  1. Open Power BI Desktop → Home > Get Data > Text/CSV
  2. Load each file from the powerbi/ folder one at a time:
    dim_date.csv   dim_port.csv   dim_species.csv   dim_vessel.csv   fact_landing.csv
  3. For each file click Transform Data → verify column types → Close & Apply
  4. Set column types: date_key = Whole Number, full_date = Date, quantity_kg / price_per_kg / total_value = Decimal Number, is_weekend / is_current = True/False

Step 2 – Build the Star Schema (Model View)

  1. Click the Model icon (left sidebar)
  2. Drag fact_landing[date_key] → dim_date[date_key]
  3. Drag fact_landing[port_key] → dim_port[port_key]
  4. Drag fact_landing[species_key] → dim_species[species_key]
  5. Drag fact_landing[vessel_key] → dim_vessel[vessel_key]
  6. Confirm all relationships are Many-to-One (*:1) with Single cross-filter direction

Step 3 – Create DAX Measures

  1. In Report View, click New Measure and add:
    Total Quantity KG = SUM(fact_landing[quantity_kg])
    Total Value = SUM(fact_landing[total_value])
    Avg Price per KG = AVERAGE(fact_landing[price_per_kg])
    Total Landings = COUNTROWS(fact_landing)

Step 4 – Build Report Visuals

VisualAxis / LegendValues
Clustered Bar Chartdim_species[common_name]Total Quantity KG
Line Chartdim_date[month_name]Total Value
Map / Filled Mapdim_port[province]Total Landings

Card KPIs (4x)–Total Landings, Total Quantity KG, Total Value, Avg Price per KG

Step 5 – Export as PDF

  1. Go to File > Export > Export to PDF
  2. Save as fisheries_2026_summary.pdf
  3. Alternative: Open this HTML file in any browser → Ctrl+P → Save as PDF
